# خلاصه‌ی کاربردی مجهول و شرطی‌ها

> نسخه‌ی فشرده‌ی `passive-and-conditionals-guide.md` — فقط پرکاربردها.
> پیش‌نیاز: جدول ۳×۴ زمان‌ها. مجهول = همان زمان‌ها + `be + V3`. شرطی = همان زمان‌ها + قاعده‌ی «فاصله».

---

# بخش اول — مجهول (Passive)

## ۱. کی مجهول؟
مجهول درباره‌ی **ترتیب و تمرکز** است، نه معنا. آنچه مهم‌تر است اول می‌آید:
- عامل نامعلوم: `My laptop was stolen.`
- عامل بدیهی: `He was arrested.` (معلوم است پلیس)
- فرآیند مهم است نه عامل: `The mixture is then heated.`
- لحن بی‌طرف و آکادمیک: `It is often argued that...`

## ۲. فرمول واحد
**`be` را در همان زمان فعل اصلی صرف کن + V3.** مفعول می‌شود فاعل؛ فاعل قبلی یا حذف یا با by.

| زمان | مجهول |
|---|---|
| Present Simple | is/are written |
| Present Continuous | is being written |
| Present Perfect | has been written |
| Past Simple | was/were written |
| Past Continuous | was being written |
| Past Perfect | had been written |
| Future Simple | will be written |
| Future Perfect | will have been written |

Perfect Continuousها و Future Continuous مجهول نمی‌شوند (`been being` ❌) — جمله را معلوم کن. در عمل ۸ زمان مجهول داری و در IELTS تقریباً فقط ۵ تای اول لازم است.

منفی/سؤالی با اولین کمکی: `hasn't been written` / `Has it been written?`

## ۳. مجهول با modal
- حال/آینده: **modal + be + V3** → `must be done`, `can be done`, `should be done`, `needs to be done`
- گذشته: **modal + have been + V3** → `It should have been tested.` / `The bug could have been avoided.`
- ❌ `It should be done yesterday` → ✅ `should have been done yesterday`

## ۴. شکل‌های غیرصرفی (پرکاربرد)
| شکل | مثال |
|---|---|
| to be + V3 | `The issue needs to be fixed.` |
| being + V3 | `I hate being interrupted.` |
| to have been + V3 | `He is thought to have stolen the money.` |

نکته‌ی بریتانیایی: `The report needs revising.` = `needs to be revised`

## ۵. افعال دو مفعولی
`give, send, tell, offer, show, teach, pay` — دو مجهول ممکن است، ولی **انسان به‌عنوان فاعل طبیعی‌تر است**:
- ✅ `I was offered a job.` / `We were told to wait.`
- نسخه‌ی دیگر به to نیاز دارد: `A certificate was given to Hossein.` (نه `given Hossein` ❌)

فعل + حرف اضافه: حرف اضافه همراه فعل می‌ماند:
- ✅ `The problem was dealt with.` (نه `was dealt` ❌)
- ✅ `The server must be looked after.`

## ۶. افعالی که مجهول نمی‌شوند
**ناگذرها** (مفعول ندارند): `happen, occur, take place, arrive, come, go, appear, disappear, die, fall, rise, exist, sleep, seem, remain, belong to, consist of, become`
- ❌ `The accident was happened` → ✅ `The accident happened`

**stateهای گذرا:** `have (=داشتن), suit, fit, resemble, cost, weigh` → ❌ `A car is had by me`

**`be born` همیشه مجهول:** ✅ `I was born in Tehran.`

**رویداد خودبه‌خودی = معلوم:** `The door opened.` / `The glass broke.` / `The temperature rose.` — مجهول (`was opened`) فقط اگر کسی انجامش داده.

## ۷. قاعده‌ی by
۸۰٪ مجهول‌های آکادمیک اصلاً by ندارند. by فقط وقتی عامل **اطلاعات مفید** اضافه کند:
- ✅ `The theory was proposed by Einstein.`
- ❌ `The window was broken by someone.` → فقط `was broken`
- ❌ `The report was written by me.` → ✅ `I wrote the report.` (عامل مهم است → معلوم)
- ابزار = **with**: `It was cut with a knife.` (نه by ❌)

## ۸. ساختارهای پرکاربرد دیگر

**get-passive (محاوره):** `He got fired.` / `My phone got stolen.` — در Speaking طبیعی، در Writing هرگز.

**مجهول غیرشخصی (طلای Task 2):**
- `It is widely believed that...` / `It is often argued that...` / `It cannot be denied that...`
- `He is believed to be a genius.` (رویداد قبل‌تر: `to have stolen`)
- دو سه تا در کل مقاله کافی است؛ زیاده‌روی مصنوعی می‌شود.

**Causative — دادن کار به دست دیگری:**
- **have/get + چیزی + V3**: `I had my car repaired.` / `I got my hair cut.`
- فرق حیاتی: `I cut my hair` (خودم) ≠ `I had my hair cut` (آرایشگر)
- معنای دوم — اتفاق ناخوشایند: `He had his wallet stolen.`
- نسخه‌ی معلوم: `have someone do` / `get someone to do` (دقت به to) / `make someone do` (اجبار) / `let someone do` (اجازه)

## ۹. مجهول در IELTS
- **Task 1 فرآیند:** ساختار پیش‌فرض = Present Simple Passive + کلمات ترتیبی (`first, then, once, finally`)
- **Task 1 نمودار:** عمدتاً معلوم (`sales rose`)؛ مجهول فقط برای روش جمع‌آوری (`The data was collected...`)
- **Task 2:** حدود ۱۵–۲۰٪ جملات؛ بیشتر از این سنگین و مبهم می‌شود
- **Speaking:** `I was told that...` / `I got promoted` / `I had my laptop upgraded`

# بخش دوم — شرطی‌ها (Conditionals)

## ۱۰. ایده‌ی اصلی: گذشته = فاصله، نه لزوماً زمان

در شرطی‌ها صرف گذشته **فاصله از واقعیت** می‌سازد، نه فاصله در زمان:
`If I had more money...` → درباره‌ی همین الان است (الان پول ندارم).

فارسی هم همین را دارد، فقط برای ادب: «می‌خواستم خواهش کنم» — خواهش مال الان است، گذشته فقط مستقیم بودن را کم کرده.

**نردبان فاصله — دو ستون که مستقل تنظیم می‌شوند:**

| | بند if (زمانِ شرط) | بند اصلی (زمانِ نتیجه) |
|---|---|---|
| پله ۰ — واقعی | If I **have** time | I **will** call you |
| پله ۱ — غیرواقعیِ حال | If I **had** time | I **would** call you |
| پله ۲ — غیرواقعیِ گذشته | If I **had had** time | I **would have** called you |

- بند if فقط زمان را عقب می‌برد؛ بند اصلی فقط modal را. برای همین ❌ `If I would have known` غلط است — دو بار علامت غیرواقعی.
- **قانون سفت:** will و would هرگز در بند if شرطی استاندارد نمی‌آیند.
- چرا گذشته `had had` می‌خواهد؟ چون `had` قبلاً برای «غیرواقعیِ حال» خرج شده.

**تست دو سؤالی:**
1. واقعی است یا خلاف واقع؟ واقعی → پله ۰
2. خلاف واقع: هنوز قابل تغییر است → پله ۱ / تمام شده → پله ۲

**تله‌ی فارسی:** «اگر پول داشتم، می‌خریدمش» مبهم است — هم پله ۱ هم پله ۲. انگلیسی مجبورت می‌کند انتخاب کنی. این تنها خطای مفهومی شرطی‌هاست؛ بقیه مکانیکی‌اند.

## ۱۱. چهار نوع اصلی

| نوع | بند if | بند اصلی | معنا |
|---|---|---|---|
| Zero | Present | Present | حقیقت همیشگی: `If you heat water, it boils.` |
| First | Present | will + V1 | آینده‌ی ممکن: `If the tests pass, I'll merge.` |
| Second | Past | would + V1 | فرضی حال: `If I had time, I would refactor.` |
| Third | Past Perfect | would have + V3 | حسرت گذشته: `If I had known, I would have told you.` |

- **Zero:** تست — اگر if را با when عوض کنی و معنا عوض نشود، Zero است.
- **First:** بند اصلی لازم نیست will باشد: `If you finish early, you can leave.` / `...we should cancel.` / `...tell him I called.` (تنوع = range)
- **Second:** `were` برای همه‌ی ضمایر: `If I were you...` (نه was در Writing). تفاوت First/Second نگرش گوینده است: `If I get the job, I'll move` (امیدوارم) ≠ `If I got the job, I'd move` (بعید می‌دانم).
- **Third:** بند اصلی سه گزینه دارد: `would have` (حتماً) / `could have` (امکانش بود) / `might have` (شاید).
- ❌ `If it will rain` → ✅ `If it rains` — بند if خودش نشانه‌ی آینده است.

## ۱۲. Mixed — شرط و نتیجه در دو زمان

از دو ستون ناهم‌ردیف انتخاب کن؛ قاعده‌ی جدیدی ندارد:
- **شرط گذشته → نتیجه حال** (پرکاربردترین): `If I had studied medicine, I would be a doctor now.`
- **ویژگی دائمی → نتیجه گذشته**: `If he spoke English, they would have hired him.`

تشخیص: آیا شرط و نتیجه در یک زمان‌اند؟ نه → mixed.
یک جمله در کل Speaking کافی است؛ زورکی جا نکن.

## ۱۳. جایگزین‌های if (پرکاربردها)

| ساختار | معنا | مثال |
|---|---|---|
| unless | مگر اینکه | `I won't deploy unless all tests pass.` |
| as long as | به شرطی که | `You can use it as long as you credit the source.` |
| in case | محض احتیاط | `Take a backup in case the disk fails.` |
| even if | حتی اگر | `Even if it costs more, it's worth it.` |
| otherwise | وگرنه | `Back it up; otherwise you'll lose everything.` |
| if it weren't for | اگر ... نبود (حال) | `If it weren't for open source, this wouldn't exist.` |
| if it hadn't been for | اگر ... نبود (گذشته) | `If it hadn't been for the backup, we'd have lost everything.` |

**سه تله‌ی unless:**
1. خودش منفی است: ❌ `Unless you don't hurry` → ✅ `Unless you hurry`
2. فقط جای «مگر اینکه» می‌نشیند، نه هر `if not`: ❌ `I'd be surprised unless he came` → ✅ `if he didn't come`
3. با نوع سوم کمتر طبیعی است → `If I hadn't been warned...`

**in case ≠ if:** `I'll take an umbrella if it rains` (واکنش — اول باران) ≠ `in case it rains` (پیشگیری — اول چتر). بعد از in case هم will ممنوع.

**امر + and/or:** `Work hard and you'll pass.` / `Hurry up or you'll miss the train.`

## ۱۴. Inversion — حذف if (فقط برای Writing، یک بار)

if را حذف کن، کمکی را ببر قبل از فاعل (همان ترتیب سؤالی):
- `Should you need help, please contact us.`
- `Were I you...` / `Were governments to invest more, congestion would fall.`
- `Had I known, I would have told you.`
- منفی بدون اختصار: ❌ `Hadn't I known` → ✅ `Had I not known`
- در Speaking تقریباً هیچ‌وقت — مصنوعی به گوش می‌رسد.

## ۱۵. همان قاعده‌ی فاصله در ساختارهای دیگر

| ساختار | یک قدم عقب (حال) | دو قدم عقب (گذشته) |
|---|---|---|
| wish | I wish I **had** more time | I wish I **had studied** harder |
| if only | If only I **knew** | If only I **had listened** |
| it's time | It's time we **left** | — |
| would rather + دیگری | I'd rather you **didn't** tell him | I'd rather we **had discussed** it |
| as if | He talks as if he **knew** everything | as if he **had seen** it |

- `wish + would` = شکایت از رفتار **دیگری**: `I wish he would stop interrupting.` — برای خودت ❌ (`I wish I would be...` → `I wish I were...`)
- `wish + could` = آرزوی توانایی: `I wish I could help.`
- `It's high time you took this seriously.` (high = خیلی وقته باید)
- `would rather + V1` برای ترجیح خودم: `I'd rather stay home.`
- as if: گذشته = باور دارم غیرواقعی است؛ حال = شاید واقعی باشد.

## ۱۶. شرطی در IELTS
- **Part 3 (پرارزش‌ترین):** سؤال فرضی → `If education were free, I imagine universities would face funding problems, although access would improve.`
- **Part 2:** جمع‌بندی با نوع سوم: `Looking back, if I had asked for help earlier, I would have saved a lot of time.`
- **Task 2:** استدلال فرضی (نوع ۲)، تحلیل پیامد (نوع ۱: `If this trend continues...`)، جمع‌بندی با unless: `Unless immediate action is taken, these problems are likely to worsen.`

## ۱۷. چک‌لیست خطاها

**مجهول:**
| ❌ | ✅ |
|---|---|
| The report has written. | has **been** written |
| It is wrote. | is **written** |
| The task will finished. | will **be** finished |
| The accident was happened. | **happened** |
| I born in Tehran. | I **was** born |
| The problem was dealt. | was dealt **with** |
| It was cut by a knife. | cut **with** a knife |
| A book was given him. | given **to** him |
| The door was opened by itself. | The door **opened** |
| It should be done yesterday. | should **have been** done |

**شرطی:**
| ❌ | ✅ |
|---|---|
| If it will rain... | If it **rains** |
| If I would have known... | If I **had** known |
| If I was you... | If I **were** you |
| Unless you don't hurry... | Unless you **hurry** |
| I wish I would be taller. | I wish I **were** taller |
| I wish I have more time. | I wish I **had** more time |
| It's time we leave. | It's time we **left** |
| I'd rather you don't tell him. | I'd rather you **didn't** tell him |
| in case it will rain | in case it **rains** |
| Hadn't I known... | **Had I not** known |

**چک بعد از هر جمله‌ی مجهول:** be در زمان درست؟ V3 نه V2؟ been جا نیفتاده؟ فعل گذراست؟ by واقعاً لازم است؟
**چک بعد از هر شرطی:** will/would در بند if نیامده؟ قابل تغییر (۲) یا تمام‌شده (۳)؟ دو بند همخوان؟ were در نوع ۲؟ کاما اگر if اول آمده؟
