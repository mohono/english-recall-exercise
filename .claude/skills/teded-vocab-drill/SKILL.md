# تمرین واژگان — TED-Ed

## ۱. این اسکیل چه چیزی تولید می‌کند

از هر ویدیوی کانال TED-Ed یک تمرین ترجمهٔ معکوس می‌سازد: **ترنسکریپت انگلیسیِ ویدیو** به واحد شکسته می‌شود، فارسیِ هر واحد نوشته می‌شود، و با زدن روی واحد اول یک کادر نوشتن اختیاری و بعد از «نمایش پاسخ»، انگلیسی اصلی به‌همراه واژه‌ها و عبارت‌های **B1 به بالا**ی آن واحد باز می‌شود.

موتور تمرین همان موتور `ielts-vocab-drill` است. تفاوت‌ها:

- **منبع** ترنسکریپت ویدیو است (supadata.ai)، نه PDF.
- **جدول واژه وجود ندارد.** واژه‌های B1+ را خودت تشخیص می‌دهی و تعریف و ترجمه‌شان را خودت می‌نویسی (بخش ۶). این مهم‌ترین تفاوت است و دقتش با توست.
- **تمرین تکمیلی نداریم.** جمله‌ای ساخته نمی‌شود؛ فقط خودِ ترنسکریپت تمرین می‌شود.
- **ویدیوی بعدی** را دفتر حساب و فهرست کانال تعیین می‌کنند، نه یک شمارهٔ ثابت.

این مخزن (`english-recall-exercise`) خانهٔ همهٔ تمرین‌هاست. **موتور و ظاهر تمرین مشترک‌اند** و در `app/` هستند؛ هر تمرین فقط یک **فایل داده** در `data/<مجموعه>/<شناسه>.js` است و هیچ HTML یا CSS یا JS در آن نیست. تمرینی که ساخته شود خودبه‌خود در نوار کناریِ نمای تمرین (`python3 serve.py`) می‌آید. به `app/` دست نزن.

```
.claude/skills/teded-vocab-drill/         ← همین اسکیل
scripts/fetch.py                          ← next / get
scripts/drill.py                          ← build / check / index (مشترک همهٔ اسکیل‌ها)
scripts/add_ipa.py                        ← آوانگاری آمریکایی
sources/teded/transcripts/<videoId>.txt   ← ترنسکریپت تمیزشده (کامیت می‌شود)
sources/teded/video-ledger.md             ← دفتر حساب
data/teded/<NNN>-<Slug>.js                ← هر ویدیو، یک فایل دادهٔ مستقل
.env                                      ← SUPADATA_API_KEY (در git نیست؛ هرگز کامیت نکن)
```

هر ویدیو **فایل دادهٔ خودش** را دارد: `DRILL({ "title", "storeKey", "source", "items": [ … ] });` با دقیقاً **یک** درس.

## ۲. وقتی بدون دستور مشخص صدا زده می‌شوی

اگر کاربر فقط «ادامه» گفت یا اسم اسکیل را آورد، **هیچ سؤالی نپرس**:

1. اجرا کن: `python3 scripts/fetch.py next`. این دستور فهرست کانال را (تازه‌ترین اول) می‌گیرد، با `sources/teded/video-ledger.md` مقایسه می‌کند و **تازه‌ترین ویدیویی را که هنوز در دفتر نیست** برمی‌گرداند. پس اگر ویدیوی تازه‌ای آپلود شده باشد خودبه‌خود همان انتخاب می‌شود، و اگر نه، ادامه از آرشیو است — از تازه‌ترینِ پردازش‌نشده به عقب.
2. در خط اول پاسخ بگو کجا هستیم: «ویدیوی ۳ — عنوان (تاریخ انتشار)». اگر `positionInChannel` برابر ۱ بود بگو «ویدیوی تازه»؛ در غیر این صورت «از آرشیو».
3. اجرا کن: `python3 scripts/fetch.py get <videoId>`.
4. شمارهٔ ویدیو = تعداد ردیف‌های دفتر + ۱. برای هر ویدیو یک فایل دادهٔ تازه می‌سازی (بخش ۸).

اگر API خطا داد یا ترنسکریپت نیامد، **همان‌جا متوقف شو و خطا را بگو.** ترنسکریپت را هرگز از حافظه یا حدس ننویس.

اگر دفتر حساب با فایل‌های `data/teded/` نخواند، **فایل‌ها مرجع‌اند**. دفتر را اصلاح کن و علتش را در یادداشت‌ها بنویس.

## ۳. ترنسکریپت

`sources/teded/transcripts/<videoId>.txt` یک خط است؛ تنها کاری که `fetch.py` کرده جمع‌کردن شکست‌خط‌های کپشن و فاصله‌های اضافه است. ترنسکریپت‌های TED-Ed نقطه‌گذاری و حروف بزرگ درست دارند و «اِ/اوم» ندارند.

- **قبل از برش، کل ترنسکریپت را بخوان.**
- اگر غلط تایپی **آشکار** کپشن دیدی (مثلاً `ao the only way` به‌جای `so the only way`)، آن را **در خود فایل ترنسکریپت** اصلاح کن و در یادداشت دفتر حساب بنویس. هیچ تغییر دیگری در متن مجاز نیست.
- نویسه‌های تایپوگرافیک (`’` `—` `“` `”`) را دست نزن. اگر متن `"` مستقیم داشت، در رشتهٔ جاوااسکریپت `\"` بگذار.

## ۴. برش واحدها

- هر واحد حدود **۶ تا ۲۰ کلمه**: جملهٔ کوتاه یک واحد؛ جملهٔ بلند از ویرگول، حرف ربط یا `—` شکسته می‌شود تا روی گوشی جا بگیرد.
- ترتیب و کلمات انگلیسی **دقیقاً** حفظ می‌شود. اگر واحدها را با یک فاصله به هم بچسبانی باید برابر ترنسکریپت شود؛ `drill.py check` همین را می‌سنجد.
- ترنسکریپت پاراگراف ندارد. `newPara: true` را روی اولین واحد و هرجا موضوع جابه‌جا می‌شود بگذار (تقریباً هر ۴ تا ۸ واحد).
- `section` استفاده نمی‌شود.

## ۵. نوشتن فارسی — قاعدهٔ اصلی

فارسیِ هر واحد نه روان و خلاصه باشد، نه آینهٔ انگلیسی. باید **شفاف** باشد: تمام اطلاعات لازم برای بازساختن جملهٔ انگلیسی در آن باشد، ولی شکل انگلیسی را لو ندهد.

**قاعدهٔ بازیابی:** هر عنصر معنایی جملهٔ انگلیسی باید از فارسی قابل استخراج باشد. اگر برای رسیدن به جملهٔ اصلی باید چیزی را حدس بزند، واحد خراب است.

**قاعدهٔ عدم انعکاس:** ترتیب کلمات انگلیسی، «یک» نکرهٔ زائد به‌جای `a`، و ساختارهای ترجمه‌ای مثل «مورد … قرار گرفت» تقلب‌اند.

**فارسی باید به سمت واژهٔ هدف هدایت کند.** وقتی واحدی واژهٔ هدف دارد، معادلی بنویس که همان واژه بیرون بیاید، نه مترادف عمومی‌اش:

- برای `to pose a question` بنویس «سؤالی مطرح کنم» — نه «سؤالی بپرسم»، که به `ask` می‌رسد.
- برای `bear in mind` بنویس «در نظر داشته باشید» — نه «یادت باشد».
- برای `were facing down a mystery` بنویس «با یک معما رودررو شده بودند» — نه «با یک معما مواجه بودند».

این با قاعدهٔ عدم انعکاس در تضاد نیست: معادل فارسیِ طبیعیِ همان مفهوم را انتخاب می‌کنی، نه اینکه ساختار انگلیسی را در فارسی بچینی.

## ۶. واژه‌ها — `words`

### کدام واژه‌ها

سطح هدف **B1 و بالاتر** (CEFR) است و شبکه **عمداً گشاد** است: هر واژه و عبارتِ B1، B2، C1 و C2 یک ورودی می‌گیرد، حتی اگر احتمال می‌دهی کاربر بعضی را بلد باشد. فقط واژه‌های پایهٔ A1/A2 (`cow`, `milk`, `farm`, `week`, `test`, …) کنار گذاشته می‌شوند. **اگر بین A2 و B1 مردد بودی، بگذار.**

- **بگیر:** واژهٔ تک، phrasal verb، اصطلاح، هم‌نشینی ثابت (`came back negative`)، ساختارهای الگودار (`be linked to`)، کاربرد مجازی (`a flap ahead`).
- **نگیر:** اسم خاص، عدد، و اصطلاح کاملاً تخصصی که در انگلیسی عمومی به کار نمی‌رود (`hemagglutinin`, `H5N1`). فارسیِ واحد معنایش را می‌رساند. اما واژه‌های علمیِ عمومی مثل `pandemic`، `outbreak`، `mutation`، `vaccine`، `susceptible` جزو شبکه‌اند.
- هر واژه **فقط در اولین واحدی** که می‌آید ورودی می‌گیرد؛ تکرارهای بعدی نه، مگر معنی یا کاربرد تازه‌ای داشته باشد.
- واژه‌های هم‌خانواده (`infect` / `infection` / `infected`): یک ورودی برای اولین صورت، و بقیه در `more`.

### قالب هر ورودی

هر ورودی را در **یک خط** بنویس:

```js
{ w: "culprit", m: "the person or thing responsible for a problem", fa: "مقصر، عامل اصلی", more: "cause · offender" },
```

- `w` — **صورت فرهنگ‌لغتی**: مصدر با `to`، اسم مفرد، عبارت ثابت در صورت پایه (`to face down`, `on record`). صورت واقعی در جملهٔ انگلیسی دیده می‌شود؛ برای این تفاوت `note` لازم نیست.
- `m` — تعریف انگلیسی **کوتاه**، به سبک فرهنگ‌لغت یادگیرندگان: یک بند، با واژه‌هایی **ساده‌تر از خود واژه**، **به معنای همین بافت**، و بدون اینکه خود واژه در تعریف بیاید.
  - `to face down` ← `to deal with a difficult problem directly, without backing away`
  - `frighteningly` ← `in a way that is very worrying`
  - `vigilant` ← `watching carefully for possible danger`
- `fa` — معادل فارسیِ همین بافت، **کوتاه** (یک تا سه کلمه یا عبارت)، طبیعی.
- `more` — **اختیاری**: مترادف، هم‌خانواده یا هم‌نشین رایج، با `·` جدا، حداکثر ۳–۴ قلم. فقط اگر مطمئنی و به یادگیری کمک می‌کند. خالی بود کلید را حذف کن.

### دقت

جدولی نیست که پشتش بایستد، پس **هر ورودی باید درست باشد.** تعریفی را که از آن مطمئن نیستی ننویس؛ در معنای همین بافت بمان (نه همهٔ معانی واژه)؛ اگر عبارت اصطلاح است، معنی مجازی‌اش را بنویس نه تحت‌اللفظی را. مترادف و هم‌نشین را از حافظه بنویس فقط وقتی مطمئنی.

## ۷. نکته — `note`

**فقط وقتی لازم است** که فارسی می‌تواند به جای دیگری ببرد یا واژه در متن کاربرد غیرمعمولی دارد. یک یا دو جمله، نه بیشتر. اکثر واحدها `note` ندارند. توضیح گرامری ننویس.

## ۸. ساخت فایل

بلوک درس را در یک فایل موقت بنویس، با این قالب (هر واحد چند خط؛ `fa:` و `en:` هرکدام سر یک خط جدا و با `"` نقل‌قول شوند):

```js
  {
    items: [
      {
        fa: "…",
        en: "In March 2024, US veterinarians were facing down a mystery.",
        newPara: true,
        words: [
          { w: "to face down", m: "…", fa: "…" },
        ],
      },
      {
        fa: "…",
        en: "…",
      },
    ]
  }
```

در رشته‌های فارسی، انگلیسی را داخل `<en>…</en>` بگذار. برای رشته‌ها از `"` استفاده کن.

بعد فایل داده را بساز و آوانگاری را اضافه کن:

```bash
python3 scripts/drill.py build teded 001-Everything-you-need-to-know-about-bird-flu "ویدیوی ۱ — Everything you need to know about bird flu" /tmp/new-drill.js --source "https://www.youtube.com/watch?v=bHB5iiDDJ-s" --key teded-bHB5iiDDJ-s
scripts/.venv/bin/python scripts/add_ipa.py data/teded/001-Everything-you-need-to-know-about-bird-flu.js
```

- شناسهٔ فایل: `<NNN>-<Slug>`؛ `NNN` سه‌رقمی و همان شمارهٔ ویدیو در دفتر. `Slug` عنوان ویدیو است بدون « - نام سخنران»، با فاصله‌ها به‌صورت خط تیره و بدون نقطه‌گذاری.
- `--source` لینک ویدیو است (در تمرین «Watch on YouTube» می‌شود) و `--key` همیشه `teded-<videoId>`.
- `build` بلوک را به فایل `data/teded/<NNN>-<Slug>.js` تبدیل می‌کند و فهرست نوار کناری را تازه می‌کند. فایلی را که هست بازنویسی نمی‌کند.
- فیلد `ipa` را دستی ننویس؛ `add_ipa.py` آن را کنار هر `en` و هر `w` می‌سازد و اجرای دوباره‌اش بی‌خطر است.
- **فایل موجود را بازتولید نکن.** برای اصلاح یک واحد فقط همان واحد را در فایل دادهٔ خودش ویرایش کن. داخل `DRILL( … );` یک JSON معمولی است: کلیدها و رشته‌ها با `"`، و بعد از آخرین عضو ویرگول نمی‌آید. بعد از هر ویرایش دوباره `drill.py check` (و اگر انگلیسی یا واژه‌ای عوض شد `add_ipa.py`) را اجرا کن.

## ۹. دفتر حساب

`sources/teded/video-ledger.md` را مستقیم ویرایش کن. یک ردیف برای هر ویدیو: شماره، `videoId`، عنوان، تاریخ انتشار، تاریخ پردازش، تعداد واحدها، تعداد ورودی‌ها. غلط‌های اصلاح‌شدهٔ ترنسکریپت و هر اتفاق دیگر در «یادداشت‌ها».

**فقط `videoId`ها را داخل بک‌تیک بگذار.** `fetch.py next` هر عبارت ۱۱‌نویسهٔ داخل بک‌تیک را شناسهٔ ویدیو حساب می‌کند.

## ۱۰. بازبینی و کامیت

1. اجرا کن:

```bash
python3 scripts/drill.py check teded/001-Everything-you-need-to-know-about-bird-flu --transcript bHB5iiDDJ-s
```

باید `OK` چاپ کند. این دستور درستیِ فایل داده، وجود `fa` و `en` در هر واحد، یکتایی `storeKey`، و — مهم‌تر از همه — **برابربودن دقیق انگلیسی واحدها با ترنسکریپت** را می‌سنجد. اگر رد شد، **کامیت نکن.**

2. فارسی واحدها را یک بار با انگلیسی مقایسه کن: شفاف است؟ به واژهٔ هدف هدایت می‌کند؟
3. **مرور پوشش:** ترنسکریپت را جمله‌به‌جمله دوباره بخوان و برای هر جمله بپرس: واژه یا عبارت B1+ ای هست که جا انداخته‌ام؟ اضافه کن.
4. `git status` را ببین. **`.env` نباید در فهرست باشد.** بعد:

```bash
git add -A && git commit -m "ویدیوی ۱ — Everything you need to know about bird flu (۶۲ واحد، ۱۲۲ ورودی)"
```

اگر مخزن ریموت دارد (`git remote` چیزی چاپ می‌کند) بعد از کامیت `git push` هم بزن؛ اگر ندارد فقط کامیت کن.

## ۱۱. آنچه نباید انجام بدهی

- متن انگلیسی را تغییر نده، خلاصه نکن، و جمله‌ای از آن نینداز (جز اصلاح غلط تایپی آشکار طبق بخش ۳).
- ترنسکریپت را هرگز از خودت ننویس؛ اگر API جواب نداد متوقف شو.
- تمرین تکمیلی یا جملهٔ ساختگی اضافه نکن.
- واژه‌های A1/A2 را ورودی نکن؛ B1+ را جا نینداز.
- توضیح گرامری ننویس؛ اگر لازم شد یک جمله در `note` کافی است.
- کلید API را در هیچ فایلی جز `.env` ننویس و `.env` را هرگز کامیت نکن.
- بیش از یک ویدیو در هر جلسه پردازش نکن.
- پیشنهاد و توصیهٔ نخواسته اضافه نکن.
